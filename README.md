# DAKA — ثبت کد تأیید مرحله ۲

سامانه ساده برای استعلام کد ملی از فایل‌های اکسل خریداران و ثبت **کد تأیید** مطابق قالب مرحله ۲.

## امکانات

- بارگذاری چند فایل اکسل لیست خریداران
- استعلام با کد ملی (باکس و دکمه بزرگ)
- نمایش ستون‌های مرحله ۲: کد ملی، نام، تقسیمات، خانوار، همراه، سهمیه، کد تأیید
- ثبت کد تأیید با پیام موفقیت و پاک شدن خودکار فرم
- انتخاب ماه و سال (مثلاً آبان ۱۴۰۵) — داده‌ها جدا ذخیره می‌شوند
- لیست موارد ثبت‌شده با امکان اصلاح و حذف
- خروجی اکسل با نام `آبان-1405.xlsx` و شیت «اطلاعات»
- فوتر: شرکت کیهان سازه پارت — ۰۹۱۵۷۴۰۷۶۱۷ — DAKA

## نسخه وب

فایل `www/index.html` را در مرورگر (ترجیحاً Chrome) باز کنید.

## نسخه اندروید

پروژه در پوشه `android/` است. با GitHub Actions روی هر پوش به `main` یک APK دیباگ ساخته و به‌عنوان Artifact آپلود می‌شود.

### اجرای دستی اکشن

Actions → **Build Android APK** → Run workflow

پس از اتمام بیلد: Artifacts → `daka-stage2-debug-apk`

### بیلد محلی

```bash
cp www/index.html android/app/src/main/assets/www/index.html
cd android
gradle wrapper --gradle-version 8.7
./gradlew assembleDebug
# خروجی: app/build/outputs/apk/debug/app-debug.apk
```

## ستون‌های قالب خروجی

| کد ملی | نام متقاضی | تقسیمات کشوری | تعداد اعضای خانوار | شماره همراه | سهمیه (کیلوگرم) | کد تأیید |
| --- | --- | --- | --- | --- | --- | --- |

نگاشت از فایل خریداران:

- نام متقاضی ← عنوان
- شماره همراه ← شماره تماس
- تعداد اعضای خانوار ← افراد تحت تکفل (+ سرپرست در صورت فعال بودن گزینه)
- سهمیه ← تعداد اعضا × سرانه (پیش‌فرض ۸ کیلوگرم) یا ستون سهمیه در فایل مبدأ
