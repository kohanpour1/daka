# DAKA — ثبت کد تأیید (نسخه ساده)

اپ ساده برای ثبت کد ملی و کد تأیید — بدون نیاز به فایل ورودی.

**شرکت کیهان سازه پارت** — ۰۹۱۵۷۴۰۷۶۱۷ — DAKA

## صفحه ۱
استان، شهرستان، بخش، روستا، شرکت تعاونی، نام کاربر  
با «ثبت و ادامه» ذخیره می‌شود و دفعات بعد می‌ماند.

## صفحه ۲
- باکس بزرگ کد ملی و کد تأیید + دکمه ثبت
- اگر کد ملی تکراری باشد، کد تأیید جدید جایگزین می‌شود
- تعداد ثبت‌شده + نمایش/ویرایش/حذف
- خروجی اکسل
- ایجاد فایل جدید (دوره جدید)
- پاکسازی همه
